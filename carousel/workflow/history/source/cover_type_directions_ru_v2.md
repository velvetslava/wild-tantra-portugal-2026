# Wild Tantra — крупные типографические обложки v2

Пять вариантов исследуют масштаб и характер заголовка. Крупная типографика используется только на обложке; тексты и факты ретрита не меняются.

1. **Wide** — широкий современный гротеск, полноэкранный wordmark.
2. **Serif** — контрастная антиква, fashion/editorial-интонация.
3. **Condensed** — сверхкрупный узкий шрифт, максимальная плотность.
4. **Blocks** — геометрическая типографика в двух цветовых полях.
5. **Bodoni** — выразительная fashion-антиква и архитектурный фрагмент.

Правка Wide: крупная дата перенесена под имя Пемы и включена в главный смысловой блок; в нижней строке осталось только место.

Правка Blocks: фотография с ванной заменена полупрозрачным ботаническим слоем в оливковом поле; типографика и двухцветная композиция сохранены.

Выбран Wide: крупный чёрно-розовый вариант перенесён в первый слайд канонической карусели `carousel_v3_vibe` без изменений остальных девяти слайдов.
